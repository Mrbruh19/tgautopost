# Auto Arsen Publisher

FastAPI-сервис для подготовки фотографий автомобилей и автоматической
публикации в Telegram и сообщество VK. Проект рассчитан на Railway с постоянным
томом `/data`.

## Что делает сервис

- трижды в день выбирает безопасный для автоматического расчёта автомобиль;
- получает курсы CNY и EUR ЦБ РФ и рассчитывает итоговую цену;
- скачивает первые 8 подходящих фотографий;
- удаляет тёмно-красную надпись автосалона со стены;
- публикует один альбом из 8 фотографий в Telegram;
- по понедельникам, четвергам и субботам публикует только
  предварительно одобренный полезный автомобильный материал;
- автоматически создаёт для одобренного материала обложку 7:5 в стиле
  AUTO ARSEN;
- при включённом VK публикует тот же автомобиль и те же 8 фотографий на стене
  сообщества;
- хранит очередь и результаты доставки в SQLite на Railway Volume;
- не дублирует VK-пост при повторной попытке после сбоя Telegram.

Расписание по умолчанию в часовом поясе `Asia/Yekaterinburg`:

- полезные материалы — `10:00` по понедельникам, четвергам и субботам;
- автомобили — ежедневно в `12:00`, `16:00`, `20:00`.

## Обязательные переменные Railway

### Telegram

- `TELEGRAM_BOT_TOKEN` — токен Telegram-бота.
- `TELEGRAM_CHAT_ID` — `@autoarsen` либо цифровой ID канала.

### VK

- `VK_AUTO_PUBLISH_ENABLED=true` — включает публикацию в VK.
- `VK_GROUP_ID` — только числовой ID сообщества, без `club` и без минуса.
- `VK_ACCESS_TOKEN` — пользовательский токен администратора сообщества с
  правами на стену и фотографии.
- `VK_API_VERSION=5.199` — версия VK API; можно оставить значение по умолчанию.

Для загрузки фотографий нужен именно **пользовательский токен администратора**.
Токен сообщества не подходит для `photos.getWallUploadServer` и приводит к
ошибке VK API 27.

### Сервис и расписание

- `PUBLISH_API_KEY` — секрет для ручных методов `/prepare` и `/publish`.
- `PUBLIC_BASE_URL` — публичный HTTPS-адрес Railway без завершающего `/`.
- `STATE_ROOT=/data` — каталог постоянного тома.
- `AUTO_PUBLISH_ENABLED=true`
- `AUTO_PUBLISH_TZ=Asia/Yekaterinburg`
- `AUTO_PUBLISH_TIMES=12:00,16:00,20:00`
- `AUTO_PUBLISH_START_DATE=2026-07-18`
- `AUTO_PUBLISH_CATCHUP_MINUTES=90`
- `AUTO_PUBLISH_RETRY_MINUTES=10`
- `CONTENT_AUTO_PUBLISH_ENABLED=true`
- `CONTENT_PUBLISH_TIME=10:00`
- `CONTENT_PUBLISH_WEEKDAYS=0,3,5` — понедельник, четверг, суббота;
- `CONTENT_PUBLISH_CATCHUP_MINUTES=90`

### Цена и контакт

- `CONTACT_TELEGRAM=@latypovars`
- `COMMISSION_RUB=50000`
- `BROKER_RUB=49000`
- `INTERNAL_MARKUP_CNY=6000`

ГЛОНАСС и доставка до города покупателя в опубликованную цену не включаются.

## Подключение VK

Если Telegram уже автоматически репостится в VK через OneMorePost или другой
внешний сервис, прямую публикацию VK в этом приложении включать не нужно:
оставьте `VK_AUTO_PUBLISH_ENABLED=false`. Полезные материалы попадут в VK тем
же действующим маршрутом, что и автомобильные посты.

Шаги ниже нужны только для прямой публикации через VK API.

1. Создайте или откройте сообщество `AUTO ARSEN | Авто из Китая`.
2. Узнайте числовой ID сообщества в разделе управления.
3. Получите пользовательский токен от аккаунта-администратора с правами
   `wall`, `photos` и долгосрочным доступом.
4. Добавьте `VK_GROUP_ID`, `VK_ACCESS_TOKEN` и
   `VK_AUTO_PUBLISH_ENABLED=true` в Railway Variables.
5. Перезапустите deployment.
6. Откройте `/health`. Поля должны показывать:

```json
{
  "status": "ok",
  "version": "3.3.0",
  "telegram_configured": true,
  "vk_auto_publish_enabled": true,
  "vk_configured": true,
  "content_auto_publish_enabled": true,
  "content_time": "10:00",
  "content_weekdays": [0, 3, 5]
}
```

Не сохраняйте токены в GitHub и не отправляйте их в сообщения.

## Надёжность двойной публикации

Сначала сервис загружает фотографии и публикует запись в VK, затем отправляет
альбом в Telegram. ID VK-поста сохраняется в SQLite сразу после успешного
`wall.post`. Если Telegram временно недоступен, следующая попытка использует
уже сохранённый VK ID и не создаёт второй пост.

Для вызова `wall.post` также используется стабильный `random_id`, поэтому
повтор после сетевого тайм-аута безопасен.

## Очередь полезных материалов

Автоматический черновик сначала проходит проверку владельца канала. Только
после явного подтверждения запись добавляется в `content_seed.json` через
GitHub. Railway получает изменение, создаёт обложку 1400×1000 и ставит
одобренный материал в ближайший свободный контентный слот.

Пустой `content_seed.json` означает, что одобренных материалов пока нет:
сервис ничего не публикует самостоятельно. SQLite отмечает каждую запись
опубликованной и не повторяет её.
